# myanki
A simple-minded Anki system, Python Flask version

# Very simple flashcard

* Python Flask web-based
* E-mail without any authentification
* Simple, tab-separated word/explanation pairs
* SRS (Spaced Repetition System)
* Optimized SRS algorithm

# How to install & use

```bash
git clone https://github.com/nomota/myanki
cd myanki
pip install -r requirements.txt
python myanki.py
```

You can now access http://127.0.0.1:8000/
Enjoy!
